# /nyx-research

Dispatch `nyx-product` via `nyx_task_dispatch` to fetch external documentation with `nyx_web_fetch`, ground vendor APIs via `nyx_docs_ground`, and publish cited specifications to `nyx_blackboard_publish`. Review and promote verified entries.
