# Changelog

All notable changes to `nyxowl` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Removed
- Removed **Claude Code**, **Codex CLI**, **Antigravity (`agy`)**, and **Cursor** host adapters, templates, detection entries, configuration values, tests, and documentation. **OpenCode v2.2.5 is now the only supported host.**
- Removed **Gemini CLI** and **Windsurf** host adapters, templates, detection entries, configuration values, and documentation.
- Removed the vendored skill tree (`skills-vendor/`), `agents/skills/registry.json`, DNA-conditional skill resolution, and bundled-skill SHA-256 integrity checks.
- Nyxowl is now **Linux-only** (including WSL2). macOS is no longer supported; `package.json`, CI, and preflight checks reject non-Linux platforms.

### Changed
- **Test-Writer context tool filter:** The generated plugin's `restrictTools` hook now uses a two-phase snapshot filter. Before MCP registration the snapshot contains only native host tools, so the filter deletes only `opencode_models`, `opencode_session_move`, `opencode_session_rename`, `opencode_worktree_create`, and `opencode_worktree_list` and preserves the rest; once any allowed Test-Writer tool appears (`testwriter_job|write|lint|gate|finish`, prefixed or bare, including wrapped entries) it keeps only allowed entries. Both object and array snapshots follow the same allowlist/denylist phases, the filter is a no-op for other agents or a missing snapshot, and it stays fail-open. A live diagnostic matrix with a temp plugin confirmed the nine-key pre-MCP snapshot and the later 39-key snapshot carrying all five MCP tools; final live re-verification is pending.
- **OpenCode is the only host** and uses the installed **OpenCode v2.2.5** contract: native `opencode.json` (`default_agent`, ordered `permissions`, `agents` with inline `system`, `commands`, `mcp.servers.nyxowl`, and a `plugins` directory), plus an ESM plugin using `ctx.permission.hook("evaluate")` and `ctx.session.hook("context")`. Launch is `opencode --standalone <path>`.
- **Skill system replaced** with exactly 11 per-agent empty slots at `agents/skills/<agent-id>/SKILL.md`. Empty slots contribute nothing to compiled prompts; an owner-authored slot is appended under `## Agent Skill`. Agent contracts now declare `skills: local`.
- First-run setup always generates the OpenCode package and reports the 11-slot filled/empty summary.

### Added
- **One-command Test-Writer install:** `npm install -g nyxowl` followed by `nyxowl <path>` now installs the rootless Test-Writer runtime under `~/.nyxowl/test-writer` (or `$NYXOWL_HOME/test-writer`) on first run, including the Python venv. `nyxowl testwriter install` repairs or forces the install, and `nyxowl testwriter status` reports wrappers, venv, store, and source. The setup path remains best-effort so the rest of Nyxowl still launches when Python/pip is unavailable, and the Test-Writer tools stay fail-closed. `NYXOWL_TESTWRITER_INSTALL=0` disables the automatic install.
- **Test-Writer rootless runtime:** Replaced the root-owned install with a user install under `$HOME/.nyxowl/test-writer`, a `0700` store at `<install>/store`, a workspace at `$HOME/tw-jobs`, and a venv at `<install>/venv`. Runtime paths are resolved at call time from `TW_INSTALL_ROOT`, `TW_STORE_ROOT`, `TW_WORKSPACE_ROOT`, `TW_TMP_ROOT`, and `TW_VENV_PYTHON`; there is no separate OS user, privileged wrapper, password prompt, `/opt/test-writer`, or `/var/lib/test-writer`. `bootstrap/install-user.sh` and `bootstrap/build-user-venv.sh` are the only install scripts. Owner approval invokes `tw-store-job` directly as the current user. M5 and M6 are complete; M7 remains pending.
- **Test-Writer M4:** Added deterministic fixed-seed flake re-runs, hidden still-vulnerable and fixed-differently variant gates, and an AST-only mutation gate with a `0.8` kill threshold and at most 8 mutants. The gate now runs 1-6; `PROVEN` requires all six. Added `VARIANT_MISSING`, `FLAKY`, `VARIANT_TOO_WEAK`, `VARIANT_OVERFIT`, `VARIANT_MISLABELED`, and `MUTATION_SCORE_LOW` routing. Variant refs/tars and mutant source are never exposed to the subagent; feedback carries only marker-free aliases and aggregate counts. Rootless self-tests grew to 203. No dependency, receipt kind, or TypeScript change.
- **Test-Writer M5:** Added canonical `proof.json` evidence with a self-verifying `proofHash`, an append-only hash-linked per-job `chain.log`, frozen `test.py` staging, and an owner-facing `REPORT.md`. Added `gate.proof`, `gate.chain`, `gate.recheck`, and the `tw-recheck` wrapper. `tw-recheck <id>` verifies the proof self-hash, effective runtime hashes, frozen input hashes, chain anchor, and state, then replays gates 1-6 read-only and compares verdict/reason/flags/gates, the vulnerable/patched/violation count blocks, mutation counts, variant statuses, and flake runs; it exits `0` only on a recomputed match and fails closed with `HASH_MISMATCH`, `CHAIN_BROKEN`, `PROOF_MISSING`, `STATE_MISMATCH`, `NO_FROZEN_TEST`, `JOB_NOT_CLOSED`, or `JOB_INVALID`. The chain refuses symlinked logs, opens appends with `O_NOFOLLOW`, and caps at 10,000 entries/8 MiB. Proof/report/recheck artifacts contain no target, test, variant, or mutant source and no raw sandbox output. Rootless self-tests grew to 217. No dependency, receipt kind, or TypeScript change.
- **Test-Writer M6:** Added an advisory finish record. `tw-gate <id> --finish` after a terminal verdict now writes a private `finish.json` with the deduplicated `INJECTION_SUSPECTED`/`SPEC_INSUFFICIENT` flags and returns `advisoryFlags`; state, `proof.json`, `chain.log`, `test.py`, and `REPORT.md` are untouched, and `tw-recheck` stays green. `tw-status` validates the record, deduplicates it, caps it at 8, and returns `[]` when absent or malformed. The broker now forwards only the five owner-set `TW_*` runtime overrides to spawned wrappers so a temporary install/store/workspace is honoured end to end. M6 also adds a model-free three-run fixture matrix (`test-writer/qa/m6_threerun.py`), a real stdio MCP parent end-to-end test (`test-writer/qa/m6_parent_e2e.mjs`), and OpenCode permission assertions for the subagent's five-tool boundary. The Test-Writer boundary is now three-layer: config denies `read`, `edit`, `glob`, `grep`, `shell`, `webfetch`, `websearch`, `subagent`, `skill`, `question`, `external_directory`, `experimental_image_generate`, and `execute` ahead of the `nyxowl_*` deny and five allows, but does not deny `opencode_list_mcp_resources` / `opencode_read_mcp_resource` / `opencode_models` or emit a wildcard deny because live QA showed each removes the allowed MCP tools from the model's tool surface; the generated permission hook enforces a local five-action allowlist for `nyx-testwriter` and fails closed for that agent if it throws; and a second `context` hook applies a two-phase filter to the per-request `event.tools` snapshot for `nyx-testwriter`: before MCP registration it deletes only the five bypassing native tools (`opencode_models`, `opencode_session_move`, `opencode_session_rename`, `opencode_worktree_create`, `opencode_worktree_list`) so MCP registration is preserved, and once an allowed tool appears it keeps only the five Test-Writer tools by suffix match for object or array snapshots (prefixed or bare, plus wrapped entries), as a no-op for other agents and a safe no-op on a missing tools snapshot. Live re-verification with the two-phase filter is pending. Partially privileged agents keep the narrower rule set and fail-open behavior, and live re-verification is pending. Rootless self-tests grew to 219. The live OpenCode host-isolation transcript remains a verifier step. No dependency, receipt kind, second MCP server, or filled skill slot was added.
- **Test-Writer verdict trust model:** Gates 2/4/5 now rest on real behavioural evidence: a vulnerable or still-vulnerable run must fail with `AssertionError` or pytest `Failed`, and the patched or fixed-differently run must pass. Detector `seen`/`attributed`/`calls` values remain in reports and counts as evidence only and are never a pass condition. A target exception stays `SETUP_ERROR_VULN:wrong_exception:<Type>`, a vulnerable pass stays `NO_DETECTOR_HIT_ON_VULN`/`UNPROVEN`, and hidden variants plus mutation remain the strength checks. The proof test is untrusted quality code inside bwrap, not a hostile-code security boundary; interpreter introspection is outside the verdict trust model, the owner reviews the test/spec, and a separate-process judge remains future work. Defense-in-depth lint hardening now also rejects `os`, `inspect`, `_settings`, `_sys`, `currentframe`, `getframe`, traceback/frame attributes (`tb`/`tb_next`/`tb_frame`/`tb_lineno`/`f_globals`/`f_locals`/`f_back`/`f_code`), `gi_frame`/`cr_frame`, and `co_consts` attribute accesses as `DYNAMIC_ESCAPE` while keeping `pytest.raises`, `exc.value`, target calls, and `tmp_path` I/O clean; a malicious test or target can still introspect the same interpreter, so this does not change the trust boundary.
- **Test-Writer M1-M3:** Deterministic Python fixtures with J1-J4 verdicts, a 13-rule static lint gate, and a bubblewrap pytest harness with a Python audit hook, canary detection, and detector attribution. Added the private job store, gates 1-3, owner wrappers, and 152 rootless self-tests. Security hardening rejects `request`/`pytestconfig`/`monkeypatch`/`mocker`, `pytest.MonkeyPatch`, plugin-manager attribute chains, dunder access, `pytest.exit`, and `SystemExit`/`KeyboardInterrupt`/`GeneratorExit`; the harness also fails forbidden fixtures in setup, blocks test-initiated reads of `/work/src` and the harness with `sensitive_read`, authenticates every report with a per-run HMAC-SHA256 MAC, cross-checks the report outcome against the real bwrap exit status, and binds detector hits to an optional `unsafe_return_contains` marker on the target's observed return. M5-M7 and M6 host-isolation verification remain pending; this adds no receipt kind, second MCP server, dependency, or filled skill slot.
- **Test-Writer subagent:** Added `nyx-testwriter` and seven brokered tools (`nyx_testwriter_job`, `nyx_testwriter_write`, `nyx_testwriter_lint`, `nyx_testwriter_gate`, `nyx_testwriter_finish`, `nyx_testwriter_prepare`, `nyx_testwriter_status`) with per-role tool scoping, Python-only v1 jobs, and a fail-closed `~/.nyxowl/test-writer` broker that never receives the canary, variants, mutants, or raw target output.
- **Docs:** Added `docs/updating.md` (upgrade, verification, rollback, and state-preservation guide), an "Updating Nyxowl" section in the README, and `CHANGELOG.md` to the published package files. Added docs link-integrity and package-manifest tests.
- **Grammar integrity:** Added `data/grammars/manifest.json` pinning the byte length and SHA-256 of the vendored Python, Go, and Rust tree-sitter grammars. Grammars are verified from the same directory as the `.wasm`, and only verified bytes are passed to the loader.
- **Bounded scanning:** `nyx_symbol_skeleton` now enforces a 2 MiB file cap and a 50,000-line cap, rejecting oversized files with `ERR_FILE_TOO_LARGE`. A 2,000,000-character parse cap, a maximum AST depth of 200, and a 50,000-node traversal budget make parsing fall back to the legacy regex outline when exceeded.

### Changed
- **Engine 2 AST accuracy:** `nyx_symbol_skeleton` now parses Python, Go, and Rust with vendored tree-sitter WebAssembly grammars (offline, no runtime network) instead of regex-only outlines, preserving the legacy outline as a fallback when a grammar is unavailable. Added language-aware symbol classification to `nyx_trace_symbol` (definitions, imports, and call sites for Python/Go/Rust, with symbol-aware import detection for TS/JS). Vendored `tree-sitter-wasms@0.1.13` grammars for Python, Go, and Rust under `data/grammars/`.
- **Cache bounds:** Grammar languages are cached per path plus verified digest (FIFO, max 32), and skeleton results are cached FIFO with a maximum of 256 entries.
- **Version single-source:** The MCP server version, bootstrap commit trailers, and PR footer now derive from `NYXOWL_VERSION` instead of hardcoded `1.0.0` literals.

## [1.0.0] - 2026-11-04

### Added
- **Universal CLI & Zero-Footprint Launcher (`src/cli/`):**
  - First-run setup (`~/.nyxowl/` `0700`, `receipt.key` `0600`, bundled skill SHA-256 verification, host detection).
  - Automatic folder classification (`empty` greenfield, `adopt-no-git`, `git-repo` with dirty-tree isolation).
  - Session-scoped host adapters for **Claude Code**, **OpenCode**, **OpenAI Codex CLI**, **Gemini CLI**, **Google Antigravity (`agy`)**, **Cursor**, and **Windsurf**.
  - Self-scoping, fail-safe host hooks (`guard`, `edit-guard`, `session-start`, `pre-compact`) with `< 150ms` p95 latency.
- **7 Heavy Runtime MCP Engines (31 `nyx_*` tools in `src/mcp/engines/`):**
  - **Engine 1 (`shield/`):** `nyx_env_inspect`, `nyx_web_fetch` (SSRF & DNS-rebinding firewall), `nyx_sanitize_untrusted`, `nyx_dep_guard` (Levenshtein typosquatting + OSV + fail-closed offline), and Exact-Value + Entropy Output Redactor.
  - **Engine 2 (`bootstrap-navigator/`):** `nyx_env_doctor`, `nyx_project_bootstrap` (Greenfield + Adopt mode with secret & 50 MB guard), `nyx_dna_extract`, `nyx_dna_get`, `nyx_symbol_skeleton` (≥80% token reduction), and `nyx_trace_symbol`.
  - **Engine 3 (`seam/`):** `nyx_seam_check` (DB ↔ ORM ↔ API ↔ UI ↔ Env graph diff), `nyx_pkg_verify`, and `nyx_docs_ground`.
  - **Engine 4 (`worktree-slice/`):** `nyx_worktree_start`, `nyx_worktree_manage`, `nyx_slice_checkpoint` (shadow refs via `GIT_INDEX_FILE`), `nyx_slice_rewind`, and `nyx_worktree_pr` (HMAC receipt gate + diff secret scan).
  - **Engine 5 (`blackboard/`):** `nyx_blackboard_publish`, `nyx_blackboard_read`, `nyx_lock_acquire`, `nyx_lock_release`, and `nyx_task_dispatch`.
  - **Engine 6 (`probe-exploit/`):** `nyx_debug_isolate`, `nyx_proc`, `nyx_slop_check`, `nyx_verify_slice` (3-strike circuit breaker + auto-rewind), and `nyx_exploit_probe` (loopback-only AppSec vectors).
  - **Engine 7 (`context/`):** `nyx_context_hydrate`, `nyx_task_handoff` (≤400 tokens), and `nyx_artifact_read`.
- **10 Canonical Agents, 6 Slash Commands & 16 Vendored Skills (`agents/`, `skills-vendor/`):**
  - Principal Tech Lead (`nyxowl`) + 9 specialized subagents (`nyx-product`, `nyx-architect`, `nyx-designer`, `nyx-db`, `nyx-api`, `nyx-ui`, `nyx-sec`, `nyx-probe`, `nyx-devops`) with strict per-role MCP tool scoping and ≤1,200-token prompt budgets.
  - Verified all 10 §13 Acceptance Scenarios in automated E2E and unit test suites.

### Fixed
- CI type-stripping for TypeScript tests on Node.js 22.13.
- Version reporting now derives from `package.json` instead of hardcoded literals.
- Unsupported Node.js versions now get an actionable preflight upgrade message instead of a `node:sqlite` import crash.
