# Changelog

All notable changes to `nyxowl` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Removed
- Removed **Claude Code**, **Codex CLI**, **Antigravity (`agy`)**, and **Cursor** host adapters, templates, detection entries, configuration values, tests, and documentation. **OpenCode v2.2.5 is now the only supported host.**
- Removed **Gemini CLI** and **Windsurf** host adapters, templates, detection entries, configuration values, and documentation.
- Removed the legacy `skills-vendor/` tree, `agents/skills/registry.json`, and DNA-conditional skill resolution; the new native/inline packages use a provenance lock instead of the old bundled-skill resolution.
- Nyxowl is now **Linux-only** (including WSL2). macOS is no longer supported; `package.json`, CI, and preflight checks reject non-Linux platforms.

### Changed
- **Skill package terminology:** Renamed the slot-era `AgentSkillSlotReport` / `getSkillSlotReport` symbols to `AgentSkillPackageReport` / `getSkillPackageReport` and `SetupResult.skillSlots` to `SetupResult.skillPackages`. The printed `Skill packages: 11/11 loaded (10 native, 1 inline)` doctor line is unchanged; `slot`-era fixture names and comments were also renamed.
- **Professional prompt pass:** Rewrote all 11 agent bodies to the six-section contract (`Mission`, `Inputs`, `Procedure`, `Hard Rules`, `Done Criteria`, `Output Format`) with explicit non-goals, role-scoped allowlisted tools, numbered procedures, untrusted-input handling, `BLOCKED`/`SPEC_INSUFFICIENT` decision rules, and receipt- or grader-bound completion criteria. Frontmatter, tools, modes, contracts, agents, engines, and dependencies are unchanged; native prompts stay within 1200 tokens and `nyx-testwriter` within 6000.
- **Dead exports:** De-exported `agentContractSchema` and `listSkillFiles` after confirming neither is imported outside its module; `AgentContractFrontmatter` and `loadAgentSkill` remain exported.
- **Packaging:** Removed `scripts/skills` from the published `files` list while keeping the vendoring script in the repository for CI and local verification.
- **Test-Writer context tool filter:** The generated plugin's `restrictTools` hook now uses a two-phase snapshot filter. Before MCP registration the snapshot contains only native host tools, so the filter deletes only `opencode_models`, `opencode_session_move`, `opencode_session_rename`, `opencode_worktree_create`, and `opencode_worktree_list` and preserves the rest; once any allowed Test-Writer tool appears (`testwriter_job|write|lint|gate|finish`, prefixed or bare, including wrapped entries) it keeps only allowed entries. Both object and array snapshots follow the same allowlist/denylist phases, the filter is a no-op for other agents or a missing snapshot, and it stays fail-open. A live diagnostic matrix with a temp plugin confirmed the nine-key pre-MCP snapshot and the later 39-key snapshot carrying all five MCP tools; live re-verification passed on attempt 2 per `test-writer/qa/EVIDENCE-M6.md`.
- **OpenCode is the only host** and uses the installed **OpenCode v2.2.5** contract: native `opencode.json` (`default_agent`, ordered `permissions`, `agents` with inline `system`, `commands`, `mcp.servers.nyxowl`, and a `plugins` directory), plus an ESM plugin using `ctx.permission.hook("evaluate")` and `ctx.session.hook("context")`. Launch is `opencode --standalone <path>`.
- **Skill system rebuilt** as 11 authored packages under `agents/skills/<agent-id>/`: 10 **native** skills registered through an absolute host `skills` root and loaded on demand with the `skill` tool, plus **nyx-testwriter** in **inline** mode with selected text embedded in its system prompt. Native prompts contain exactly one loader line and no skill body; the inline testwriter prompt is budgeted at 6000 tokens. Agent contracts declare `skills: native` or `skills: inline`.
- First-run setup and `nyxowl doctor` always regenerate the OpenCode package and report `Skill packages: 11/11 loaded (10 native, 1 inline)`.
- **Prompt-contract hotfix:** Clarified every subagent `subagent-summary-v1` output (receipt objects only, string `contractsPublished`, no duplicate keys), made `nyx-product` fetch external docs only when the task needs them, gave `nyx-architect` the exact published schemas plus promote and retry rules, and told `nyxowl` to skip research/architecture roles on docs-only or single-file changes and reject malformed subagent summaries. Added gate-owner dispatch coverage so the primary dispatches every verify/seam/slop/exploit owner instead of only one writer, stale or missing receipt artifacts are re-dispatched rather than read, and the `orchestrator-report-v1` field types are strict (string-array `slicesCompleted`, `{id,status}`-only `receipts`, non-null `prUrlOrPath`). Extended the body with greenfield-from-empty-folder bootstrap, dispatch economy that skips roles whose tools are not required, anti-hallucination evidence rules, and token-discipline guidance, moving detailed playbooks into the native `nyxowl` skill. Added parallel-dispatch policy for independent, disjoint work and explicit skipping of unneeded roles, with dispatch-decision guidance in the native skill. Frontmatter, tools, contracts, engines, schemas, and skills are unchanged.

The gate now runs 1-6; `PROVEN` requires all six. Added `VARIANT_MISSING`, `FLAKY`, `VARIANT_TOO_WEAK`, `VARIANT_OVERFIT`, `VARIANT_MISLABELED`, and `MUTATION_SCORE_LOW` routing. Variant refs/tars and mutant source are never exposed to the subagent; feedback carries only marker-free aliases and aggregate counts. Rootless self-tests grew to 203. The chain refuses symlinked logs, opens appends with `O_NOFOLLOW`, and caps at 10,000 entries/8 MiB. Proof/report/recheck artifacts contain no target, test, variant, or mutant source and no raw sandbox output. Rootless self-tests grew to 217. No dependency, receipt kind, or TypeScript change.

- **Test-Writer verdict trust model:** Gates 2/4/5 now rest on real behavioural evidence: a vulnerable or still-vulnerable run must fail with `AssertionError` or pytest `Failed`, and the patched or fixed-differently run must pass. Detector `seen`/`attributed`/`calls` values remain in reports and counts as evidence only and are never a pass condition. A target exception stays `SETUP_ERROR_VULN:wrong_exception:<Type>`, a vulnerable pass stays `NO_DETECTOR_HIT_ON_VULN`/`UNPROVEN`, and hidden variants plus mutation remain the strength checks. The proof test is untrusted quality code inside bwrap, not a hostile-code security boundary; interpreter introspection is outside the verdict trust model, the owner reviews the test/spec, and a separate-process judge remains future work. Defense-in-depth lint hardening now also rejects `os`, `inspect`, `_settings`, `_sys`, `currentframe`, `getframe`, traceback/frame attributes (`tb`/`tb_next`/`tb_frame`/`tb_lineno`/`f_globals`/`f_locals`/`f_back`/`f_code`), `gi_frame`/`cr_frame`, and `co_consts` attribute accesses as `DYNAMIC_ESCAPE` while keeping `pytest.raises`, `exc.value`, target calls, and `tmp_path` I/O clean; a malicious test or target can still introspect the same interpreter, so this does not change the trust boundary.

Added the private job store, gates 1-3, owner wrappers, and 152 rootless self-tests. Security hardening rejects `request`/`pytestconfig`/`monkeypatch`/`mocker`, `pytest.MonkeyPatch`, plugin-manager attribute chains, dunder access, `pytest.exit`, and `SystemExit`/`KeyboardInterrupt`/`GeneratorExit`; the harness also fails forbidden fixtures in setup, blocks test-initiated reads of `/work/src` and the harness with `sensitive_read`, authenticates every report with a per-run HMAC-SHA256 MAC, cross-checks the report outcome against the real bwrap exit status, and binds detector hits to an optional `unsafe_return_contains` marker on the target's observed return. M5 and M6 are complete and the live M6 host-isolation verdict passed on attempt 2 per `test-writer/qa/EVIDENCE-M6.md`; M7-lite and full M7 landed in PR D; this adds no receipt kind, second MCP server, dependency, or filled skill slot.
- **Test-Writer subagent:** Added `nyx-testwriter` and seven brokered tools (`nyx_testwriter_job`, `nyx_testwriter_write`, `nyx_testwriter_lint`, `nyx_testwriter_gate`, `nyx_testwriter_finish`, `nyx_testwriter_prepare`, `nyx_testwriter_status`) with per-role tool scoping, Python-only v1 jobs, and a fail-closed `~/.nyxowl/test-writer` broker that never receives the canary, variants, mutants, or raw target output.
- **Docs:** Added `docs/updating.md` (upgrade, verification, rollback, and state-preservation guide), an "Updating Nyxowl" section in the README, and `CHANGELOG.md` to the published package files. Added docs link-integrity and package-manifest tests.
- **Grammar integrity:** Added `data/grammars/manifest.json` pinning the byte length and SHA-256 of the vendored Python, Go, and Rust tree-sitter grammars. Grammars are verified from the same directory as the `.wasm`, and only verified bytes are passed to the loader.
- **Bounded scanning:** `nyx_symbol_skeleton` now enforces a 2 MiB file cap and a 50,000-line cap, rejecting oversized files with `ERR_FILE_TOO_LARGE`. A 2,000,000-character parse cap, a maximum AST depth of 200, and a 50,000-node traversal budget make parsing fall back to the legacy regex outline when exceeded.

### Changed
- **Engine 2 AST accuracy:** `nyx_symbol_skeleton` now parses Python, Go, and Rust with vendored tree-sitter WebAssembly grammars (offline, no runtime network) instead of regex-only outlines, preserving the legacy outline as a fallback when a grammar is unavailable. Added language-aware symbol classification to `nyx_trace_symbol` (definitions, imports, and call sites for Python/Go/Rust, with symbol-aware import detection for TS/JS). Vendored `tree-sitter-wasms@0.1.13` grammars for Python, Go, and Rust under `data/grammars/`.
- **Cache bounds:** Grammar languages are cached per path plus verified digest (FIFO, max 32), and skeleton results are cached FIFO with a maximum of 256 entries.
- **Version single-source:** The MCP server version, bootstrap commit trailers, and PR footer now derive from `NYXOWL_VERSION` instead of hardcoded `1.0.0` literals.
- **Engine 2 AST/trace coverage:** `nyx_symbol_skeleton` and `nyx_trace_symbol` now cover Java, Ruby, PHP, and C# with vendored tree-sitter WebAssembly grammars, in addition to Python, Go, and Rust. Java/C# interface methods are reported as exported without an explicit `public` modifier, and top-level Ruby `def`/`def self.` symbols are reported as `function` rather than `method`.
- **Per-glob coverage gates:** `vitest.config.ts` now enforces `src/core/**` and `src/mcp/engines/**` at 85% lines/branches and `src/cli/**` at 75% lines/branches alongside the existing global 80/65/80/80 thresholds.

### Fixed
- **Duplicate Test-Writer license:** `scripts/skills/vendor.mjs` now excludes the primary license by its actual `local` path, so `nyx-testwriter` no longer lists `LICENSE-CC-BY-SA-4.0` as both its primary and an additional license. The lock's `additionalLicenses` is `[]`; no skill bytes or hashes changed.
- **FastAPI route-return attribution:** The route-return regex no longer spans a following route handler, so a handler's response fields are no longer attributed to the preceding endpoint.

## [1.0.0] - 2026-11-04

### Added
- **Universal CLI & Zero-Footprint Launcher (`src/cli/`):**
  - First-run setup (`~/.nyxowl/` `0700`, `receipt.key` `0600`, bundled skill SHA-256 verification, host detection).
  - Automatic folder classification (`empty` greenfield, `adopt-no-git`, `git-repo` with dirty-tree isolation).
  - Session-scoped host adapters for **Claude Code**, **OpenCode**, **OpenAI Codex CLI**, **Gemini CLI**, **Google Antigravity (`agy`)**, **Cursor**, and **Windsurf**.
  - Self-scoping, fail-safe host hooks (`guard`, `edit-guard`, `session-start`, `pre-compact`) with `< 150ms` p95 latency.
- **7 Heavy Runtime MCP Engines (31 `nyx_*` tools in `src/mcp/engines/`):**
  - **Engine 1 (`shield/`):** `nyx_env_inspect`, `nyx_web_fetch` (SSRF & DNS-rebinding firewall), `nyx_sanitize_untrusted`, `nyx_dep_guard` (Levenshtein typosquatting + OSV + fail-closed offline), and Exact-Value + Entropy Output Redactor.
  - **Engine 2 (`bootstrap-navigator/`):** `nyx_env_doctor`, `nyx_project_bootstrap` (Greenfield + Adopt mode with secret & 50 MB guard), `nyx_dna_extract`, `nyx_dna_get`, `nyx_symbol_skeleton` (≥80% token reduction), and `nyx_trace_symbol`.
  - **Engine 3 (`seam/`):** `nyx_seam_check` (DB ↔ ORM ↔ API ↔ UI ↔ Env graph diff), `nyx_pkg_verify`, and `nyx_docs_ground`.
  - **Engine 4 (`worktree-slice/`):** `nyx_worktree_start`, `nyx_worktree_manage`, `nyx_slice_checkpoint` (shadow refs via `GIT_INDEX_FILE`), `nyx_slice_rewind`, and `nyx_worktree_pr` (HMAC receipt gate + diff secret scan).
  - **Engine 5 (`blackboard/`):** `nyx_blackboard_publish`, `nyx_blackboard_read`, `nyx_lock_acquire`, `nyx_lock_release`, and `nyx_task_dispatch`.
  - **Engine 6 (`probe-exploit/`):** `nyx_debug_isolate`, `nyx_proc`, `nyx_slop_check`, `nyx_verify_slice` (3-strike circuit breaker + auto-rewind), and `nyx_exploit_probe` (loopback-only AppSec vectors).
  - **Engine 7 (`context/`):** `nyx_context_hydrate`, `nyx_task_handoff` (≤400 tokens), and `nyx_artifact_read`.
- **10 Canonical Agents, 6 Slash Commands & 16 Vendored Skills (`agents/`, `skills-vendor/`):**
  - Principal Tech Lead (`nyxowl`) + 9 specialized subagents (`nyx-product`, `nyx-architect`, `nyx-designer`, `nyx-db`, `nyx-api`, `nyx-ui`, `nyx-sec`, `nyx-probe`, `nyx-devops`) with strict per-role MCP tool scoping and ≤1,200-token prompt budgets.
  - Verified all 10 §13 Acceptance Scenarios in automated E2E and unit test suites.

### Fixed

- Version reporting now derives from `package.json` instead of hardcoded literals.
- Unsupported Node.js versions now get an actionable preflight upgrade message instead of a `node:sqlite` import crash.
